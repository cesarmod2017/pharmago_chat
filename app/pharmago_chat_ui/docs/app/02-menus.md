## Menu Relatorios

## Menu Módulos
 - Temos a conexão com a rede local da farmacia, se conectando ao servidor do ERP
 - Para celulares que ainda não foram conectados a rede, tem a opção de "Rede" que ira abrir uma pagina para localização dos computadores da rede onde o servico está instalado. Ou Ler QR COde onde um outro celular já conectado ira compartilhar um QRCode com os dados de conexão assim o novo device basta ler o qrcode para se conectar a rede.
 - Menu Contagem de Estoque: acesso ao módulo de contagem de estoque geral
 - Menu: BRI - Balanço Rotativo: acesso ao modulo do BRI Balanco Rotativo Inteligente
 - Menu: Aprovação de tarefas BRI: acesso ao gestor para acompanhar as tarefas do BRI dos operadores, pondendo aprovar ou reprovar tarefas.
 - Menu: Autorização: serve para o gestor gerar codigos de autorização para a contagem de estoque para a liberação do reset e edição, ou pesquisar por nome, acessar relatorios etc.
